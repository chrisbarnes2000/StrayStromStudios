## 🛠️ Tech Stack & Compliance

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide React, Motion.
- **Backend**: Express.js with Vite middleware integration.
- **Database**: Google Cloud Firestore with granular attribute-based `firestore.rules`.
- **AI Intelligence**: Modern `@google/genai` TypeScript SDK with server-side proxy encapsulation.
- **Styling**: Bento Grid dark slate aesthetic with WCAG AA compliance and accessible reading themes.
